# Contributing to TeamRunner

Thanks for your interest in contributing!

## Not accepting pull requests yet

TeamRunner is in early development, and we are not accepting pull requests
yet. Pull requests opened now will be closed unmerged, so please don't put
time into one.

What helps most right now is an issue: bug reports, questions, and ideas are
all very welcome. Please open one in this repository's Issues tab, or, if you
have no GitHub account, write to hello@teamrunner.ai. Security problems go to
security@teamrunner.ai (see SECURITY.md), not to an issue.

We will announce here when pull requests open.
